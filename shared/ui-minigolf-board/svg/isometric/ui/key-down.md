# key-down (ui)

board: ui-minigolf-board

as key-up) with a dark down arrow (#1E293B) centred on the cap. Putts the
ball south.

Palette: primary #F5F0E1, secondary #D8CDB4, outline #1E293B.
Geometry: key-cap rect (14,14 36x36) + down-pointing triangle.
